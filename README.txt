ランダムどうぶつ図鑑 — 手描きイラスト対応版

機能
- 100種類以上の動物からランダム出題
- 通常ランダム／未完成を優先モード
- 画像ファイル（PNG/JPG/WebP等、8MB以下）のイラスト登録
- 登録したイラストを優先表示
- 描いた動物の数、カテゴリ一覧、お気に入り
- 写真はWikimedia Commonsから検索し、出典ページへのリンクを表示

重要：イラストの保存について
アップロードしたイラストは、このブラウザのIndexedDBに保存されます。サーバーにはアップロードされず、別の端末や別ブラウザとは同期されません。ブラウザのデータを消すと登録した絵も消える場合があります。大切な絵は元ファイルを手元にも保管してください。

公開手順（GitHub Pages）
1. https://github.com/ でログインし、Public repository を作成（例: random-doubutsu-zukan）。
2. ZIPを解凍して index.html、README.txt、.nojekyll をリポジトリ直下にアップロード。
3. Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: /(root) → Save。
4. Pagesに表示されるURLを開く。公開まで数分かかる場合があります。

注意
- GitHub Pagesは公開ウェブサイトです。個人情報はリポジトリに置かないでください。
- これはサーバー不要の静的サイトです。ユーザーのイラストは各ブラウザ内にのみ保存されます。
- 端末間同期やオンラインバックアップを実現するには、別途データベース／ストレージを追加する必要があります。
